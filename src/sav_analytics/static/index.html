Топлайны из SPSS без ручной сборки

Загрузите массив .sav — приложение прочитает метаданные, предложит типы вопросов, соберёт баннеры и выгрузит готовый Excel со статистическими тестами.

Здесь же будет вход в приложение, когда появится авторизация.

Структура за минуту

Variable и value labels, multiple-response sets, дихотомии и матрицы шкал распознаются автоматически. Ручная правка — там, где она нужна.

Статистика как в SPSS

Subgroup/Rest, попарные сравнения, Bonferroni, сравнение волн, NPS и CSAT. Полный аудит тестов выгружается отдельным файлом.

Веса и raking

Готовый вес из массива или расчёт методом IPF по нескольким целевым распределениям с диагностикой сходимости.

Анализ

Связь переменных

Тест выбирается по типам переменных. p-value корректируется по всем карточкам рабочей области (Benjamini–Hochberg), вывод делается по скорректированному.

Открытые ответы

Кодификатор

Тема ищет ответы запросами со всеми формами слов. Слова строки должны встретиться вместе, строки темы — любая; «цен*» — буквальный префикс, «-курьер» — исключение. Отметка человека перекрывает запрос. Темы становятся вопросом с несколькими ответами и работают в таблицах, фильтрах и баннере.

    Пропуски по анкете

    Найденные коды пропуска по ветке

    Предлагаются только коды без подписи у переменных, где подписаны хотя бы две категории, и только вне диапазона подписанных кодов. Подписанный ноль и переменные вовсе без подписей не предлагаются — там заглушку от настоящего нуля по данным не отличить, отметьте её в карточке вопроса вручную.

    Проект изменён в другом окне

      Ваш ввод в редакторе не потерян. «Повторить поверх» сохранит его на новой версии проекта; «Перезагрузить» покажет чужие изменения и оставит ваш ввод в редакторе, чтобы сохранить его снова.
