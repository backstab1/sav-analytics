# sav-analytics

Веб-приложение для подготовки аналитических Excel-топлайнов из массивов SPSS `.sav`.
Оно читает данные и метаданные файла, помогает привести структуру анкеты в порядок,
настроить перекодировки, баннеры и фильтры, а затем выгружает готовый `.xlsx`.

> **Статус:** рабочий локальный прототип. Основной сценарий от загрузки SAV до скачивания
> Excel реализован и покрыт тестами. Авторизации и production-инфраструктуры пока нет.

## Что уже работает

### Импорт и проекты

- загрузка `.sav` размером до 250 МБ;
- проверка расширения и корректности файла;
- неизменяемое хранение оригинала, размера и SHA-256;
- библиотека ранее загруженных проектов;
- скачивание исходного SAV;
- повторное распознавание структуры без замены исходного файла.

### Структура исследования

- чтение variable labels, value labels, форматов, measurement level и пропусков SPSS;
- автоматическое определение ролей и типов вопросов;
- чтение SPSS multiple-response sets;
- группировка дихотомий и однотипных шкал вида `Q5_1...Q5_n` в multiple и matrix;
- переключение между логическими вопросами и исходными столбцами SAV;
- ручная корректировка названия, типа, роли, включения в отчёт и порядка вопросов;
- автоматическая и ручная настройка специальных ответов;
- предпросмотр распределений и описательной статистики.

### Расчётные настройки

- числовые перекодировки по диапазонам;
- объединение категорий в новые группы;
- проверка пересекающихся правил и предпросмотр результата;
- обычные и двухуровневые вложенные баннеры;
- единые для всего баннера правила Subgroup/Rest и попарных тестов: confidence level,
  порог малой базы и опциональная поправка Bonferroni;
- попарные сравнения подгрупп внутри блока с результатами в примечаниях Excel;
- сравнение независимых волн с предыдущей или выбранной контрольной волной, включая
  одинаковые подгруппы вложенного баннера, стрелки в Excel и аудит тестов;
- индивидуальная пометка шкал как NPS (`0–10`) или CSAT (`1–5`) с фиксированными
  группами, итоговыми показателями и специализированными z-тестами балансов;
- применение готовой положительной весовой переменной из SAV с нормализацией к среднему 1,
  взвешенными показателями и эффективной базой Киша;
- расчёт проектного веса методом raking/IPF по нескольким целевым распределениям,
  ограничениям веса и допуску 0,1 п.п. с диагностикой сходимости, design effect и
  распределений до/после;
- обязательная колонка Total и предпросмотр баз;
- именованные фильтры с группами `И`/`ИЛИ` глубиной до двух уровней;
- условия по single choice, multiple response и перекодировкам;
- отдельная база вопроса и общий фильтр отчёта.

### Excel-топлайн

Кнопка **«Скачать Excel»** формирует книгу с листами:

- `Содержание` — навигация по вопросам;
- `topline_main` — доли от полной базы;
- `topline_filter` — доли от валидной базы для вопросов с пропусками.

В отчёт входят выбранные вопросы, Total, колонки выбранного баннера (если он настроен),
индивидуальные базы вопросов и общий фильтр. Для шкал и числовых переменных считаются
среднее, медиана, минимум, максимум, стандартное отклонение и стандартная ошибка;
для шкал также выводится Top-2. Включённые для блока сравнения Subgroup/Rest отмечаются
зелёной или красной заливкой, а результаты с невзвешенной базой ниже заданного порога —
серой.

Кнопка **«Скачать статистику»** формирует UTF-8 `statistics.txt` с полным аудитом
Subgroup/Rest и попарных сравнений: базами, числителями, оценками, ожидаемыми частотами,
дисперсиями, доверительными интервалами, статистиками, p-value, скорректированным alpha
и причинами пропуска тестов.

## Быстрый запуск

Нужен Python 3.12 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m uvicorn sav_analytics.api:app --reload
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Интерактивная документация
API доступна по адресу [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

Локальные проекты сохраняются в `.data/projects` и исключены из Git.
Каталог можно изменить переменной `SAV_ANALYTICS_DATA_DIR`, а максимальный размер загрузки —
`SAV_ANALYTICS_MAX_UPLOAD_BYTES`.

### Docker

```powershell
docker compose up --build
```

Приложение будет доступно на порту `8000`, данные сохранятся в Docker volume `sav_data`.

## Проверка изменений

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m ruff check .
```

Сейчас набор содержит 52 теста для импорта SAV, распознавания структуры, API,
перекодировок, баннеров, вложенных фильтров, предпросмотров, структуры XLSX и
эталонных расчётов z-test, Welch t-test и Subgroup/Rest.

## Устройство проекта

```text
src/sav_analytics/
├── api.py             # FastAPI и HTTP-модели
├── repository.py      # локальное хранилище проектов и конфигураций
├── settings.py        # переменные окружения
├── core/
│   ├── sav_reader.py  # чтение SAV и построение структуры
│   ├── inference.py   # определение типов и ролей
│   ├── topline.py     # предпросмотр распределений и статистик
│   ├── recoding.py    # перекодировки
│   ├── banner.py      # баннерные колонки
│   ├── filtering.py   # базы и фильтры
│   └── report.py      # генерация Excel
└── static/            # текущий русскоязычный веб-интерфейс
```

Подробная постановка задачи находится в [docs/requirements.md](docs/requirements.md),
целевая production-архитектура — в [docs/architecture.md](docs/architecture.md).
Эти документы описывают и будущие функции, поэтому не всё перечисленное там уже реализовано.

## Что пока не реализовано

- пользователи, роли и авторизация;
- PostgreSQL, Redis, очередь фоновых расчётов и версионирование отчётов;
- ручной выбор и изменение порядка включённых волн, расчёт raking отдельно внутри волн,
  цели по проектным перекодировкам и выгрузка
  рассчитанного веса отдельным Excel-файлом;
- корреляции;
- ручное создание и разгруппировка структуры вопросов;
- production-развёртывание, резервное копирование и CI/CD.

## Конфиденциальность

Исходные SAV, сформированные отчёты, локальная база проектов и секреты исключены из Git.
Не добавляйте исследовательские данные в репозиторий: для production потребуется отдельное
защищённое хранилище, контроль доступа и резервное копирование.
