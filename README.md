# sav-analytics

Веб-приложение для анализа количественных исследований из SPSS `.sav` файлов.

## Цель

Ускорить обработку исследовательских массивов без потери точности: разобрать структуру SAV, настроить типы вопросов, перекодировки, баннеры, базы и фильтры, затем сформировать статистически корректный Excel-топлайн.

## Минимальная версия

1. Создание проекта и загрузка неизменяемой копии SAV.
2. Чтение данных и метаданных SPSS.
3. Автоматическое определение типов вопросов с ручным исправлением.
4. Группировка и разгруппировка множественных вопросов.
5. Перекодирование переменных, включая возрастные группы.
6. Настройка обычных и вложенных баннеров.
7. Настройка баз, фильтров и итогового веса.
8. Расчёт долей и описательных статистик.
9. Проверка различий между подгруппами, Total/Rest и волнами.
10. Выгрузка Excel-листов `Содержание`, `topline_main`, `topline_filter`, `Correlations` и файла `statistics.txt`.

Подробные подтверждённые требования находятся в [docs/requirements.md](docs/requirements.md), рекомендуемая техническая архитектура — в [docs/architecture.md](docs/architecture.md).

## Конфиденциальность

Исходные SAV, выгруженные отчёты, локальные базы данных и секреты исключены из Git. Они должны храниться в защищённом хранилище приложения, а не в репозитории.

## Статус

Начат первый рабочий вертикальный срез без авторизации:

- создание проекта из `.sav`;
- неизменяемое хранение исходника с размером и SHA-256;
- чтение данных, labels, value labels, форматов, measurement level и пользовательских пропусков;
- автоматическое предположение типов вопросов и ролей переменных;
- чтение SPSS multiple-response sets и осторожная группировка дихотомий вида `Q5_1...Q5_n`;
- русскоязычный экран обзора вопросов и переменных;
- API для списка проектов, карточки проекта и скачивания оригинального SAV.

В текущем интерфейсе также работают:

- библиотека ранее загруженных проектов;
- редактирование названия, типа и роли вопроса;
- включение и исключение вопросов из будущего отчёта;
- сохраняемый порядок вопросов;
- вкладка исключённых вопросов;
- предпросмотр распределений от Total и валидной базы;
- среднее, медиана, минимум, максимум, стандартное отклонение и стандартная ошибка для числовых вопросов и шкал.
- создание, редактирование и удаление числовых перекодировок по диапазонам;
- проверка пересекающихся диапазонов и предпросмотр категорий, пропусков и значений вне диапазона.
- объединение исходных подписанных значений в новые непересекающиеся категории;
- компактные блоки однотипных переменных `Q15_1...Q15_n` для multiple и matrix;
- дочерние пункты блока с едиными настройками типа, роли и включения в отчёт;
- автоматическое и ручное назначение специальных ответов вроде «Затрудняюсь ответить»;
- повторное распознавание структуры уже загруженного проекта без замены исходного SAV.
- создание обычных баннерных блоков из single choice и перекодировок;
- вложенные баннеры глубиной до двух уровней с полным пересечением категорий;
- обязательный первый столбец Total и предпросмотр баз, включая нулевые.

Авторизация, ручное редактирование структуры, PostgreSQL и очередь расчётов будут добавляться следующими срезами. Локальное файловое хранилище изолировано интерфейсом репозитория и не является окончательной production-БД.

## Локальный запуск

Нужен Python 3.12+.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m uvicorn sav_analytics.api:app --reload
```

После запуска откройте `http://127.0.0.1:8000`. Загруженные проекты сохраняются в `.data/projects` и игнорируются Git.

Проверки:

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\ruff.exe check .
```

Альтернативно приложение запускается командой `docker compose up --build`.
