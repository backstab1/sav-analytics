# sav-analytics

Веб-приложение для анализа количественных исследований из SPSS `.sav` файлов.

## Цель

Ускорить обработку исследовательских массивов без потери точности: разобрать структуру SAV, настроить типы вопросов, перекодировки, баннеры, базы и фильтры, затем сформировать статистически корректный Excel-топлайн.

## Минимальная версия

1. Создание проекта и загрузка неизменяемой копии SAV.
2. Чтение данных и метаданных SPSS.
3. Автоматическое определение типов вопросов с ручным исправлением.
4. Группировка и разгруппировка множественных вопросов.
5. Перекодирование переменных, включая возрастные группы.
6. Настройка обычных и вложенных баннеров.
7. Настройка баз, фильтров и итогового веса.
8. Расчёт долей и описательных статистик.
9. Проверка различий между подгруппами, Total/Rest и волнами.
10. Выгрузка Excel-листов `Содержание`, `topline_main`, `topline_filter`, `Correlations` и файла `statistics.txt`.

Подробные подтверждённые требования находятся в [docs/requirements.md](docs/requirements.md).

## Конфиденциальность

Исходные SAV, выгруженные отчёты, локальные базы данных и секреты исключены из Git. Они должны храниться в защищённом хранилище приложения, а не в репозитории.

## Статус

Проект находится на этапе подробного проектирования пользовательских экранов и статистических правил.
